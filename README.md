# the-first-repository

## Default workflow

Create new work inside this repository, not in a separate folder. The helper script below creates a dated project folder under the repo root, so everything is tracked by the same Git history.

Run:

```powershell
.\scripts\New-Project.ps1 my-project
```

See [WORKFLOW.md](WORKFLOW.md) for the short version.

For a quick backup of the whole workspace, run:

```powershell
.\scripts\Backup-Workspace.ps1
```
